# Kitchen Deals — Logo & Brand Spec

## Logo Concept

Chef's hat with integrated percent (%) badge — kitchen + deals in one flat, geometric mark.

## Colors

| Name | Hex | Usage |
|---|---|---|
| Olive | #3c5b0a | Primary — mark, wordmark accent, buttons, links |
| Yellow | #fee348 | Accent — percent badge, highlights, CTAs |
| Black | #000000 | Text, wordmark |
| White | #ffffff | Backgrounds, dark-bg mark variant |
| Gray | #666666 | Secondary text |
| Light Gray | #f5f5f5 | Backgrounds |
| Border | #c4c4c4 | Borders, dividers |

## Typography

- **Display:** Georgia, 'Times New Roman', 'Palatino Linotype', serif
- **Body:** system-ui, -apple-system, 'Segoe UI', Helvetica, Arial, sans-serif

| File | Dimensions | Usage |

| safari-pin-icon.svg | 64×64 | Safari pinned tab |

## Clear Space

Minimum clear space around the logo: 1× the height of the "D" in "DEALS" on all sides.

## Minimum Size

- Logo lockup: 120px wide minimum
- Favicon mark only: 16px minimum

## Usage Rules

- Do not stretch or distort the logo
- Do not change the colors
- Do not add effects (shadows, gradients, outlines)
- Do not place the logo on busy backgrounds
- Do not rotate the logo
